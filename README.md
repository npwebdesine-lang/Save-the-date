# Save the Date · נתיב ואוראל

A static, responsive Hebrew (RTL) "Save the Date" page for Nativ & Orel's wedding — 17.12.2026.

- `index.html` / `style.css` / `script.js` — no build step
- `assets/couple.jpg` — the couple's photo
- "הוסף ליומן" opens a menu with a pre-filled Google Calendar link and an `.ics` download (19:30 Israel time)
- `.github/workflows/pages.yml` deploys to GitHub Pages on every push to `main`

Preview locally: `python3 -m http.server` and open http://localhost:8000.
